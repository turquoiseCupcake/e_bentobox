# 🍱 E-Bentobox

An innovative Flutter app MVP designed to solve the "Naubusan ng Ulam" problem for university students. E-Bentobox allows students to reserve and customize their daily meals from local carenderias a day in advance, ensuring their favorite dishes are ready for pick-up during busy lunch breaks.

## 🌟 Key Features

* **Next-Day Reservations:** Students can pre-order their meals for the following day, giving carenderia vendors predictability for their market runs.
* **BYOB (Bring Your Own Bento) & Eco-Packaging:** Focuses on sustainability by allowing compartmentalized bento drop-offs.
* **QR Code Tracking:** Fast and easy order fulfillment. Vendors simply scan a generated QR sticker on the bento box to notify students that their meal is ready for pickup.
* **Vendor Dashboard:** An ultra-simple, clutter-free interface for carenderia owners to accept or reject orders without navigating complex menus.
* **"Time Travel" Demo Mode:** A custom backend feature that artificially advances the server time by 24 hours, allowing developers to present the full multi-day app lifecycle in a single presentation.

## 🛠️ Tech Stack

* **Frontend:** Flutter (Dart)
* **State Management:** Riverpod / Provider
* **Backend:** Custom API on a VPS (Node.js/Python)
* **Database:** PostgreSQL / MySQL
